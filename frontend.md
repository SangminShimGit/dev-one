# Frontend — Generated Data Theme

## Overview

| Field | Value |
|-------|-------|
| Theme | Generated Data Theme v1.0.0 |
| Base | Shopify Dawn (Online Store 2.0) |
| Layout | `layout/theme.liquid` |
| Docs | [Shopify theme docs](https://shopify.dev/docs/storefronts/themes) |

## Directory map

| Folder | Purpose |
|--------|---------|
| `layout/` | Base HTML shell (`theme.liquid`, `password.liquid`) |
| `templates/` | JSON templates wiring sections to pages |
| `sections/` | Modular, theme-editor-configurable UI blocks (50 sections) |
| `snippets/` | Reusable Liquid partials (60 snippets) |
| `assets/` | CSS, JS, and static assets |
| `config/` | `settings_schema.json`, `settings_data.json` |
| `locales/` | Translation and schema strings |

## Rendering flow

```
layout/theme.liquid
  └── JSON template (e.g. templates/product.json)
        └── sections (e.g. sections/main-product.liquid)
              └── snippets (e.g. snippets/price.liquid)
```

Section groups (`header-group.json`, `footer-group.json`) bundle related sections for the theme editor.

## CSS architecture

- **Global base:** `assets/base.css`
- **Components:** `assets/component-*.css` — shared UI (buttons, cards, facets, cart, etc.)
- **Sections:** `assets/section-*.css` — page-specific section styles
- **Design tokens:** CSS custom properties in `layout/theme.liquid` `:root` block (colors, fonts, spacing, media)

Sections load CSS via `{{ 'component-card.css' | asset_url | stylesheet_tag }}`.

## JavaScript architecture

| File | Role |
|------|------|
| `assets/constants.js` | Shared constants |
| `assets/pubsub.js` | Pub/sub event bus |
| `assets/global.js` | Core theme behavior |
| `assets/cart.js` | Cart page logic |
| `assets/cart-drawer.js` | Slide-out cart |
| `assets/product-form.js` | Add-to-cart form |
| `assets/product-info.js` | Product page updates |
| `assets/facets.js` | Collection filtering |
| `assets/predictive-search.js` | Header search |
| `assets/media-gallery.js` | Product media gallery |
| `assets/quick-add.js` | Quick add from collection grids |

Scripts use `defer`. Core scripts load from `theme.liquid`; feature scripts load from their sections.

## Liquid conventions

- Sections include `{% schema %}` for theme editor settings
- Reuse via `{% render 'snippet-name', param: value %}`
- Multi-line logic via `{% liquid %}`
- Settings labels use translation keys (`t:sections...`)
- JSON templates may be auto-generated by the theme editor — edit with caution

## Theme settings → CSS variables

Defined in `layout/theme.liquid` from `config/settings_schema.json`:

- **Typography:** `--font-body-*`, `--font-heading-*`, scale variables
- **Colors:** `--color-base-*`, `--gradient-base-*`
- **Layout/media:** `--media-*`, `--page-width`, spacing and border tokens

## Conventions

- **Sections:** `main-*` for page-level sections; feature names for marketing blocks (`slideshow`, `featured-collection`)
- **CSS:** `component-*` for shared UI; `section-*` for section-specific styles
- **JS:** one file per interactive feature, named to match its section or snippet
- **Classes:** BEM-like naming (e.g. `card__heading`, `button--secondary`)
